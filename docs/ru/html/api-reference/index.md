## Обзор API

### Два режима вызова

```text
┌─────────────────────────────────────────┐
│      Функции пакета (удобный режим)       │
│  html.Extract(data) → *Result, error    │
│  Внутренне используют sync.Pool          │
│  для повторного использования Processor  │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│       Processor (режим экземпляра)        │
│  p, _ := html.New(cfg)                  │
│  defer p.Close()                        │
│  result, err := p.Extract(data)         │
│  ✓ Повторное использование кэша          │
│  ✓ Сбор статистики  ✓ Журнал аудита      │
└─────────────────────────────────────────┘
```

### Правила именования функций

| Паттерн | Именование | Пример |
|------|------|------|
| Базовый | `Extract*` | `Extract`, `ExtractText` |
| Из файла | `Extract*FromFile` | `ExtractFromFile` |
| С контекстом | `Extract*WithContext` | `ExtractWithContext` |
| Из файла + контекст | `Extract*FromFileWithContext` | `ExtractFromFileWithContext` |

### Информация о модуле

- **Путь к модулю**: `github.com/cybergodev/html`
- **Версия Go**: 1.25+
- **Зависимости**: `golang.org/x/net`, `golang.org/x/text`

## Предустановленные конфигурации

Начинайте от предустановки и при необходимости корректируйте, избегая ручного прописывания конфигурации с нулевыми значениями (нулевое значение `Config` нельзя использовать напрямую):

| Предустановка | Назначение |
|------|------|
| `DefaultConfig()` | Универсальный сценарий, баланс функциональности и производительности |
| `TextOnlyConfig()` | Только извлечение чистого текста, отключение всех медиа, максимальная производительность |
| `MarkdownConfig()` | Вывод изображений и ссылок в inline-формате Markdown |
| `HighSecurityConfig()` | Среда с высокими требованиями к безопасности: ужесточение лимитов, сокращение тайм-аутов, включение аудита |

Подробнее см. [Конфигурация](./core/config).

## Поиск API по сценарию

Распространённые потребности и соответствующие точки входа:

| Потребность | Рекомендуемый API | Документация |
|------|----------|------|
| Только чистый текст | `ExtractText` / `Processor.ExtractText` | [Функции пакета](./core/functions) |
| Markdown-вывод | `ExtractToMarkdown` или `MarkdownConfig()` | [Форматы вывода](./modules/output) |
| Извлечь все ресурсы-ссылки | `ExtractAllLinks` | [Извлечение ссылок](./modules/links) |
| Пакетная параллельная обработка | `ExtractBatch` / `ExtractBatchFiles` | [Пакетная обработка](./modules/batch) |
| Пользовательская идентификация контента | интерфейс `Scorer` + `Config.Scorer` | [Определение интерфейсов](./types/interfaces) |
| Аудит событий безопасности | `AuditConfig` + `AuditSink` | [Система аудита](./modules/audit) |
| Высокочастотное переиспользование + кэш | долго живущий `Processor` через `html.New()` | [Processor](./core/processor) |
