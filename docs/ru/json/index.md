# Библиотека обработки JSON

`github.com/cybergodev/json` — высокопроизводительная потокобезопасная Go-библиотека для обработки JSON. Она предоставляет богатый набор операций с JSON, включая парсинг, запросы, модификацию, валидацию и форматирование, сохраняя 100% совместимость со стандартной библиотекой `encoding/json`.

## Основные возможности

- **100% совместимость с encoding/json** — бесшовная замена стандартной библиотеки без изменения существующего кода
- **Потокобезопасность** — все операции безопасны при конкурентном доступе, поддержка высоконагруженных сценариев
- **Запросы по путям** — Path-выражения в стиле JSONPath, включая подстановочные знаки и срезы
- **Типобезопасное получение** — обобщённый API (`GetTyped[T]`) и методы приведения типов (`SafeGet`)
- **Потоковая обработка** — поддержка больших файлов и потоковой обработки формата JSONL/NDJSON
- **Защита** — встроенная валидация ввода, ограничение глубины, обнаружение опасных паттернов
- **Высокопроизводительный кэш** — интеллектуальное кэширование, оптимизация предразбора, переиспользование объектов из пула
- **Расширяемость** — система хуков, пользовательские кодировщики, валидаторы

## Быстрое знакомство за 30 секунд

```go
package main

import (
	"fmt"
	"github.com/cybergodev/json"
)

func main() {
	data := `{"name": "CyberGo", "version": 1, "tags": ["json", "go"]}`

	// 1. Получение по пути
	name := json.GetString(data, "name")
	fmt.Println("Name:", name)

	// 2. Изменение значения
	updated, _ := json.Set(data, "version", 2)
	fmt.Println("Updated:", updated)

	// 3. Валидация
	if json.Valid([]byte(data)) {
		fmt.Println("Valid JSON")
	}

	// 4. Получение со значением по умолчанию
	desc := json.GetString(data, "description", "Описание по умолчанию")
	fmt.Println("Description:", desc)

	// 5. Декодирование в структуру
	type Config struct {
		Name    string   `json:"name"`
		Version int      `json:"version"`
		Tags    []string `json:"tags"`
	}
	var config Config
	json.Unmarshal([]byte(data), &config)
	fmt.Printf("Config: %+v\n", config)
}
```

## Обзор функциональности

### Операции с путями

| Возможность | Функции | Описание |
|------|------|------|
| Получение значения | `Get`, `GetString`, `GetInt`... | Поддержка вложенных путей, индексов массивов |
| Пакетное получение | `GetMultiple` | Получение значений нескольких путей за один парсинг |
| Получение со значением по умолчанию | `GetString`, `GetInt` и др. | Передача параметра defaultValue |
| Установка значения | `Set` | По умолчанию автоматически создаёт несуществующие пути (Config.CreatePaths) |
| Удаление значения | `Delete` | Удаление указанного пути |

### Кодирование и декодирование

| Возможность | Функции | Описание |
|------|------|------|
| Кодирование | `Marshal`, `MarshalIndent` | 100% совместимость с encoding/json |
| Декодирование | `Unmarshal`, `Parse`, `ParseAny` | Поддержка обобщений и типобезопасности |
| Форматирование | `Prettify`, `Compact` | Красивое форматирование/сжатие JSON |

### Расширенные возможности

| Возможность | Функции/типы | Описание |
|------|-----------|------|
| Обобщённый API | `GetTyped[T]` | Типобезопасное обобщённое получение |
| Предразбор | `Processor.PreParse`, `Processor.GetFromParsed` | Один парсинг — множество запросов |
| Предкомпиляция путей | `Processor.CompilePath`, `Processor.GetCompiled` | Нулевой повторный разбор при высокочастотных запросах по одному пути |
| Параллельная итерация | `NewParallelIterator` | Параллельные Map/Filter/ForEach со встроенным пулом worker'ов |
| Безопасное получение | `SafeGet` → `AccessResult` | Цепочечное преобразование типов |
| Потоковая обработка | `NDJSONProcessor` | Построчная потоковая обработка с контролем памяти |
| Обработка JSONL | `StreamLinesInto[T]` | Логи/конвейеры данных |
| Валидация Schema | `ValidateSchema` | Валидация JSON Schema |

## Характеристики производительности

- **Быстрый путь без аллокаций** — доступ по одиночному ключу и построение ключа кэша через стековый буфер, меньше аллокаций в куче
- **Интеллектуальный кэш** — автоматическое кэширование горячих путей, поддержка прогрева кэша
- **Пул объектов** — переиспользование промежуточных объектов, снижение нагрузки на GC
- **Параллельная потоковая обработка** — потоковая обработка JSONL с параллельной работой нескольких worker'ов (`StreamJSONLParallel`)
- **Оптимизация предразбора** — один парсинг большого JSON для множества запросов

## Краткое руководство по выбору

| Сценарий | Рекомендуемое решение |
|------|----------|
| Простой запрос | `GetString(data, "path")` |
| Со значением по умолчанию | `GetString(data, "path", "default")` |
| Типобезопасность | `GetTyped[User](data, "user")` |
| Несколько путей в одном JSON | `Processor` + `PreParse` |
| Один путь в разных JSON | `Processor` + `CompilePath` |
| Большой файл | `Processor.ForeachFile` |
| Параллельная обработка большого массива | `NewParallelIterator` |
| Конвейер JSONL | `StreamLinesInto[T]` |
| Недоверенный ввод | `SecurityConfig()` |
